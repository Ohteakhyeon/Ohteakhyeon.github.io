## 1. 개요

Linux 서버 운영에 필요한 기본 명령어와
각 명령어의 역할을 정리한다.

## 2. 파일 및 디렉터리 관리

| 명령어 | 설명 |
|---|---|
| pwd | 현재 작업 디렉터리 확인 |
| ls | 파일 및 디렉터리 목록 확인 |
| cd | 작업 디렉터리 이동 |
| mkdir | 디렉터리 생성 |
| touch | 빈 파일 생성 또는 타임스탬프 갱신 |

## 3. 시스템 상태 확인

| 명령어 | 설명 |
|---|---|
| top | 실시간 프로세스 및 자원 사용량 확인 |
| free -h | 메모리 사용량 확인 |
| df -h | 파일 시스템의 디스크 사용량 확인 |
| uptime | 시스템 가동 시간 및 부하 확인 |

## 4. 정리

서버 운영 및 장애 분석을 위해서는
시스템 상태를 확인하고 분석할 수 있어야 한다.
